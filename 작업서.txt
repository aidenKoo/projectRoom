1) 사용자 플로우/정책
1.1 가입/로그인
가입 접근: 추천인 이름(선택) + 월 가입코드(필수, 해당 YYYYMM만 유효).
설문(가입 리서치)
공개: 이름, 나이, 키, 사진(1~5장/JPG·PNG ≤10MB), 직업, 학력, MBTI, 취미(다중), 지역(시도/시군구), 자취여부, 장점어필(≤500자).
비공개(선택, 스킵 가능): 재산수준(중간/꽤많음/많음/미응답), 외모·몸매 자신감(1~5/미응답), 성격·가치관 간단 설문.
선호도 랭킹(1~5위): 나이/키/지역/MBTI/취미유사/학력/직업군… 적게 선택할수록 영향↑ (가중: 1위=5…5위=1, 필요 시 ×(5/k) 보정).
동의: 약관/개인정보/민감정보(선택입력) 고지, 마케팅 선택 동의.
1.2 한도 규칙 (기본값)
월간 시도(요청) 한도: 15회. 보낸 즉시 1회 소진, 취소해도 복구 없음.
월간 성공(매칭 성사) 한도: 5회. 성공 5회 달성 시 해당 월 추가 성사 불가.
동시 진행 한도: 3건. accepted/chatting 상태 기준, 종료 전까지 슬롯 점유.
월 리셋: 매월 1일 00:00 KST에 시도/성공 카운터 0.
일관 정책(교차검증 완료)
성공 한도 5회 달성 시: 요청 버튼 비활성화. 과거 요청이 뒤늦게 수락될 경우 자동 거절.
요청·수락 모두에서 한도/슬롯 재검증(경합 안전).
1.3 매칭 라이프사이클(상태)
requested (A→B 요청; A.monthly_attempts+1)
 ├─(B 수락)→ accepted + chatting (양측 monthly_successes+1, concurrent_matches+1, 메시지/전화번호 가능)
 ├─(n일 미응답)→ ignored (자동 종료; 암묵적 ‘무시’)
 └─(취소)→ ended
accepted/chatting
 ├─(종료)→ ended  (슬롯 회수)
 └─(연애중 전환)→ ended + (전환자 status=dating, 프로필 비노출)
전화번호 노출: accepted 이후 버튼으로 1회 노출(감사로그).
1.4 종료/평점/블랙
종료 시(선택): 👎 텀즈 다운 / 👍 텀즈 업 / 👍👍 투 텀즈 업
업: 이유 아이콘 최대 3개(매너/대화/사진유사/시간약속/관심사/적극성/예의…)
다운: 사유 1개 필수(무례/약속파기/사진불일치/과음·흡연/지각/위생/홍보 등) → 블랙 여부 확인
블랙=Y: 자유사유(≤200자), 양방향 매칭·노출 차단.
ignored: 평점 생략/무응답 플래그만 집계.
평점/블랙은 외부 비노출, 내부 품질·안전·추천 보정에 사용(양호 시 ‘매너 배지’ 등 긍정 뱃지 가능).
1.5 리더보드/상태
유저 상태: active(활성) / pause(쉬는중) / dating(연애중).
리더보드: active 노출, pause는 ‘쉬는중’ 배지(요청 비활성 옵션), dating 비노출.
내 상태는 사용자가 직접 전환 가능.
2) 랭킹/추천(0~100)
2.1 단일방향 확률
YouLike(u→v)  = σ( wC*ContentSim(u,v) + wM*MF(u,v) + wX*CTR(u,v,ctx) )
TheyLike(v→u) = σ( wC*ContentSim(v,u) + wM*MF(v,u) + wX*CTR(v,u,ctx, Z_app(u; group=v)) )
ContentSim: 공개필드 유사도(나이/키/거리·지역/MBTI/취미 자카드/학력/직업/자취/PR임베딩) + 선호도 랭킹 가중.
MF: implicit-ALS(좋아요/요청/매칭 신뢰도 가중) → 시그모이드로 [0,1].
CTR 모델: (XGBoost/LR/FM) + 컨텍스트(시간/랭크/신규·인기).
오프정책 보정: IPS/SNIPS (impressions에 propensity 로깅).
2.2 상호 결합·재랭킹
Base = HarmonicMean(YouLike, TheyLike)                    # [0,1]
Adj  = CalibrateToUserPrefs(u, Base)                       # 상위N 속성비율을 사용자 1~5위 중요도 분포로 근사
Div  = DiversityExposure(u, Adj)                           # 군집거리 늘리기, 신규 가산, 인기 clip
2.3 외모 보정(최대 15% 캡, 내부용)
appearance_score∈[0,100] → 그룹(성별/연령대/지역대) 표준화 Z_app.
Aterm = tanh( ( Z_app(u;group=v) + 0.3*Z_app(v;group=u) ) / 4 ).
Final = Div * ( 1 + clamp(Aterm*0.15, -0.15, +0.15) ).
Score = round(100 * Final).
이중 안전장치: (1) 모델 계수 제한, (2) 최종 ±15% 캡. 점수는 UI 비노출, 긍정 카피만 안내.
2.4 피드/탐색
기본 정렬: Score 내림차순.
탐색 슬롯 α%: LinUCB/Thompson으로 신규·저노출을 삽입, 학습 데이터 확보.
일일 노출 상한(과부하 방지) 및 연속 거절 시 다양성/템포 조절.
3) 외모 추정지표(appearance_score)
3.1 산식
like_rate     = likes / max(impressions, 1)
click_rate    = photo_clicks / max(impressions, 1)
request_rate  = requests / max(impressions, 1)

# 베이즈 스무딩(m=100, 그룹 평균 prior)
smoothed(x) = (obs + m*group_mean) / (impr + m)

# 그룹 표준화(성/연령/지역 단위)
z = (smoothed - μ_g) / σ_g
norm = clamp(50 + 10*z, 0, 100)

SelfConf(1~5 → 20/40/60/80/100, 0=미응답→50)

appearance_score = clamp(0.4*SelfConf + 0.3*like_norm + 0.2*click_norm + 0.1*request_norm, 0, 100)
appearance_confidence = min(1, impressions/300)
UX: 점수 자체 비노출. “프로필 반응이 좋아요 👍”, “사진을 바꿔보면 관심이 더 늘 수 있어요” 등 긍정적 메시지만.

6) 트랜잭션/동시성 의사코드
# 요청
tx:
  u = lock_user(requester)
  v = lock_user(target)
  assert u.status != 'dating' and v.status != 'dating'
  assert not is_blacklisted(u,v) and not is_blacklisted(v,u)
  assert u.monthly_attempts < 15
  create_match(u,v,state='requested')
  u.monthly_attempts += 1
commit

# 수락
tx:
  u = lock_user(requester)  # match.a_user_id
  v = lock_user(accepter)   # match.b_user_id
  assert u.concurrent_matches < 3 and v.concurrent_matches < 3
  assert u.monthly_successes < 5 and v.monthly_successes < 5
  update match.state='accepted', accepted_at=now()
  u.monthly_successes += 1; v.monthly_successes += 1
  u.concurrent_matches += 1; v.concurrent_matches += 1
  enable_phone_access(match_id)
commit

# 종료/연애중
tx:
  m = lock_match(match_id)
  if end_type == 'dating':
     set caller.status='dating'
  if m.state in ('accepted','chatting'):
     dec caller.concurrent_matches
  set m.state='ended', m.end_reason=(end_type=='dating' ? 'dating' : 'normal'), m.ended_at=now()
commit
7) Admin 콘솔 (요약)
RBAC: Owner(Admin 전권)/Admin/Moderator/Analyst/Support + 2FA(OTP) + 감사로그.
대시보드: DAU/신규/노출·좋아요·요청률/상호매칭/슬롯포화/연애중 전환/신고·블랙/배치 상태.
회원관리: 목록(필터/검색/일괄액션)/상세(공개·비공개·카운터·평판·히스토리)/상태변경/보정/제재.
매칭현황: 리스트/상세/강제종료/번호권한 회수/채팅 열람(권한 분리).
신고·블랙: 접수→조사→판단 워크플로우, 블랙 목록/해제.
평점/품질: 👍/👍👍/👎 분포, 사유 탑N, 아웃라이어, 개입(사진가이드 푸시).
가입코드/배치: 월 코드 생성·상태/사용 현황, 배치 잡 모니터(appearance/ALS/ignored).
정책: 탐색비율, 외모 캡, 캘리브레이션 강도, 한도치, A/B 토글.
리포트/내보내기: CSV/Parquet, 워터마크·만료 링크.

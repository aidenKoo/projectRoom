## 📋 개요

관리자 웹앱의 '매칭 현황 모니터링' 페이지 개발을 완료했습니다. 이 페이지에서 관리자는 특정 사용자의 ID를 검색하여 해당 사용자의 추천 큐(Recommendation Queue)를 실시간으로 조회하고, 추천 점수와 사유를 확인할 수 있습니다.

---

## ✅ 완료된 작업 (v13)

### 1. 관리자 웹앱: 매칭 현황 모니터링 페이지 구현

**파일**: `apps/admin-web/src/pages/MatchingStatus.tsx`, `apps/admin-web/src/App.tsx`

**구현 내용**:
- **페이지 및 라우팅**: `MatchingStatus.tsx` 페이지 컴포넌트를 생성하고, 사이드바 메뉴와 라우팅을 설정했습니다.
- **UI 구현**: Ant Design의 `Input.Search`와 `Table` 컴포넌트를 사용하여 사용자 ID 검색 및 추천 큐 결과를 표시하는 UI를 구현했습니다.
- **API 연동**: 백엔드의 `/admin/match/queue` 엔드포인트를 호출하여 데이터를 가져오는 로직을 구현했습니다.
